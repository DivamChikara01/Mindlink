# MindLink Research Pack

Put these files inside your existing `mindlink_ai_starter` folder:

- `make_research_figures.py`
- `build_research_report.py`

## Step 1: Make figures

```bash
python make_research_figures.py
```

Creates graphs in:

```text
results/figures/
```

## Step 2: Build written report files

```bash
python build_research_report.py
```

Creates:

```text
MINDLINK_ONE_PAGE_SUMMARY.md
MINDLINK_RESEARCH_REPORT_DRAFT.md
MINDLINK_PROFESSOR_EMAIL_DRAFT.md
```

## Step 3: Use these for Yiwen/professor outreach

Do not send raw terminal screenshots. Send:

1. One-page summary
2. 2–3 graphs
3. GitHub link
4. Short demo video
5. Email asking for feedback, not begging for a lab position
