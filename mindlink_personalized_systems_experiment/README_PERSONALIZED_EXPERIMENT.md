# MindLink Personalized Systems Experiment

Put `compare_personalized_systems.py` inside your existing `mindlink_ai_starter` folder.

Run:

```bash
python compare_personalized_systems.py
```

This compares:

1. SVM only
2. Personalized baseline deviation only
3. Combined SVM + personalized baseline

The key question is whether the combined system improves over the SVM-only system.

Outputs go into the `results/` folder.
